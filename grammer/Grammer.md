
# Dog Class Implementation with Function Definition

## Class Declaration

```
class Dog {
public func isBark() => integer;
};
```

## Class Implementation
```cpp
implement Dog {
    func isBark() => integer {
        return(1);
    }
}
```

### Description
- **Dog Class**: Defines a class `Dog` with a public function `isBark` that returns an integer.
- **Function Implementation**: The `isBark` function is implemented to return `1`, indicating the dog is barking.
